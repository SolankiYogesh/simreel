How to test QR code scanning in the iOS Simulator

QR scanners are hard to test in the Simulator because there is no camera to point at a code. With SimReel you can show any QR code to your scanner and watch your metadata delegate receive the decoded value.

A typical QR scanner

Most iOS QR scanners use AVCaptureMetadataOutput:

final class ScannerViewController: UIViewController, AVCaptureMetadataOutputObjectsDelegate {
    let session = AVCaptureSession()

    override func viewDidLoad() {
        super.viewDidLoad()
        guard let device = AVCaptureDevice.default(for: .video),
              let input = try? AVCaptureDeviceInput(device: device),
              session.canAddInput(input) else { return }
        session.addInput(input)

        let output = AVCaptureMetadataOutput()
        if session.canAddOutput(output) {
            session.addOutput(output)
            output.setMetadataObjectsDelegate(self, queue: .main)
            output.metadataObjectTypes = [.qr]
        }

        let preview = AVCaptureVideoPreviewLayer(session: session)
        preview.frame = view.bounds
        preview.videoGravity = .resizeAspectFill
        view.layer.addSublayer(preview)

        DispatchQueue.global().async { self.session.startRunning() }
    }

    func metadataOutput(_ output: AVCaptureMetadataOutput,
                        didOutput objects: [AVMetadataObject],
                        from connection: AVCaptureConnection) {
        for case let code as AVMetadataMachineReadableCodeObject in objects {
            print("Scanned:", code.stringValue ?? "")
        }
    }
}

In the Simulator, without a camera, this code never reaches the delegate. With SimReel it does.

Show a QR code to your scanner

  1. Install SimReel (brew install --cask SolankiYogesh/tap/simreel, or download it) and open it. Your booted simulators are enabled automatically.
  2. Run your app and open the scanner screen (relaunch it if it was already running).
  3. In SimReel, choose QR code, type any text or URL, and the code appears in your scanner’s preview. Your delegate receives the value within a fraction of a second.

Or do it from the command line, which is handy in scripts and UI-test setup:

simreel set-source --back --qr "https://example.com/ticket/42"

What to test

  • Different payloads — URLs, plain text, Wi-Fi configuration strings, contact cards and your app’s own deep links.
  • Existing QR images — use the Image source with a PNG of a real code, or a Video that contains one.
  • Failure cases — switch to an image with no code, or a damaged code, to check your empty and error states.
  • Front and back cameras — set the source on each camera separately.

Details worth knowing

  • Detection runs a few times per second, so your delegate may be called repeatedly while a code stays in view — the same as on a device. De-duplicate in your code if needed.
  • Reported bounds are normalized (0–1) relative to the camera frame.
  • QR codes are verified. Other symbologies the Simulator can decode (EAN, Code 128, PDF417 and others) are supported on a best-effort basis.
  • Frames are 1280×720, so very small QR codes inside an image may be harder to read.

Troubleshooting

  • The delegate is never called. Make sure metadataObjectTypes is set after the output is added to the session, and that the simulator shows Camera active in SimReel.
  • The preview is blank. Relaunch your app after SimReel enables the simulator.
